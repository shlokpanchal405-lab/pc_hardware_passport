TASK 4 — CHIPSET / PLATFORM DEVICES
PC HARDWARE PASSPORT | DAY 2

SYSTEM
Laptop: ASUS TUF Gaming A15 FA506NCG
Evidence source: PowerShell Get-PnpDevice -PresentOnly output supplied for this assignment.

DETECTED DEVICES AND THEIR ASSOCIATED BUSES

1. AMD USB 3.10 eXtensible Host Controller
   Bus / interface: USB 3.x
   Role: Provides host-controller functionality for USB devices and ports.
   Evidence: Device class USB; device name includes "AMD USB 3.10 eXtensible Host Controller".

2. Standard NVM Express Controller
   Bus / interface: PCI Express (PCIe) / NVMe
   Role: Storage-controller interface used by the installed NVMe SSD.
   Evidence: Device class SCSIAdapter; device name "Standard NVM Express Controller". An NVMe WD PC SN5000S SSD was also detected.

3. Realtek PCIe GbE Family Controller
   Bus / interface: PCI Express (PCIe) / Ethernet
   Role: Wired network interface.
   Evidence: Device class Net; device name includes "PCIe GbE".

4. Realtek 8852BE Wireless LAN WiFi 6 PCI-E NIC
   Bus / interface: PCI Express (PCIe) / Wi-Fi
   Role: Wireless network interface.
   Evidence: Device class Net; device name includes "PCI-E NIC".

5. AMD SMBUS
   Bus / interface: SMBus
   Role: Low-speed system-management communication interface.
   Evidence: Device class System; device name "AMD SMBUS".

6. AMD High Definition Audio Device
   Bus / interface: High Definition Audio (HD Audio)
   Role: Audio controller / audio-device interface.
   Evidence: Device class MEDIA; device name "AMD High Definition Audio Device".

7. AMD I2C Controller
   Bus / interface: I²C
   Role: I²C controller used for communication with compatible low-speed peripherals.
   Evidence: Device class System; two entries named "AMD I2C Controller".

8. AMD GPIO Controller
   Bus / interface: GPIO
   Role: General-purpose input/output controller for platform signals.
   Evidence: Device class System; device name "AMD GPIO Controller".

INTERPRETATION / LIMITATION
The supplied Windows device list confirms that these devices/controllers are present. It does not, by itself, prove that every listed controller is a discrete component of the motherboard chipset; some functions may be integrated into the AMD processor or platform SoC. They are therefore documented as detected platform devices and associated interfaces, without claiming a specific chipset architecture.

EVIDENCE COMMAND
Get-PnpDevice -PresentOnly | Select-Object Class, FriendlyName

The device names and classes in this report were taken from the command output supplied by the user. No driver installation or update was performed.
